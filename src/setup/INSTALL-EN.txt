Mustek Studio — installation on another computer

1. Run MustekStudio-Setup.exe on Windows 10 x64.
2. Select an installation folder. By default the application is installed
   for the current user and does not require administrator privileges.
3. Optionally create a desktop shortcut.
4. Keep "Complete scanner setup and open Mustek Studio" selected at the end.

If WinUSB is already installed, the application opens directly.
Otherwise the scanner connection assistant opens:
  - connect the Mustek 1200 UB Plus to USB;
  - click Configure WinUSB and approve the Windows administrator prompt;
  - in Zadig select only USB ID 05D8:4002;
  - choose WinUSB on the right and click Install Driver;
  - wait for success, then open Mustek Studio.

Zadig is included; no separate download is needed. You can reopen the
connection assistant from Start — Mustek Studio — Scanner connection and setup.

Settings and working pages are stored in MustekStudio.Data inside the
application folder. Updates preserve settings and working pages.
The uninstaller offers to keep or delete PDF and PNG files and working pages
in the data folder. Export folders outside the data folder remain available.
Back up this directory and exported files to keep your documents.
Choose an installation folder writable by your user account.

Choose a folder for PDF and PNG exports on first launch. If you cancel,
the application uses MustekStudio.Data\scans. You can change the folder in
Settings. Remove all clears the document after confirmation and keeps the
image files.

Mustek Studio checks for updates on startup. You can also use Check for updates
in Settings. After confirmation, the update installs and the application reopens.

The installer works offline. Mustek Studio uses the .NET Framework included
with Windows 10. Installing WinUSB requires a separate administrator confirmation.
