Mustek Studio — установка на другой компьютер

1. Запустите MustekStudio-Setup.exe на Windows 10 x64.
2. Выберите папку установки. По умолчанию программа устанавливается
   для текущего пользователя и не требует прав администратора.
3. При необходимости отметьте создание ярлыка на рабочем столе.
4. В конце оставьте включённым «Завершить настройку сканера и открыть
   Mustek Studio».

Если WinUSB уже установлен, приложение откроется сразу. Если сканер ещё
не настроен, появится помощник подключения:
  - подключите Mustek 1200 UB Plus к USB;
  - нажмите «Настроить WinUSB» и подтвердите запрос Windows;
  - в Zadig выберите сканер строго с USB ID 05D8:4002;
  - справа выберите WinUSB и нажмите Install Driver;
  - дождитесь успешного завершения и откройте Mustek Studio.

Zadig включён в установщик, скачивать его отдельно не нужно.
Повторно открыть помощник можно из меню «Пуск» — Mustek Studio —
«Подключение и настройка сканера».

Настройки и рабочие страницы сохраняются в MustekStudio.Data внутри папки
программы. При обновлении рабочие страницы и настройки сохраняются.
При удалении Setup предлагает сохранить или удалить PDF, PNG и рабочие
страницы из папки данных. Выбранные папки за пределами папки данных остаются
доступны после удаления.
Для резервного копирования сохраните MustekStudio.Data и экспортированные файлы.
Не устанавливайте приложение в папку, недоступную текущему пользователю для записи.

При первом запуске выберите папку сохранения PDF и PNG. При отмене
используется MustekStudio.Data\scans. Папку можно изменить в настройках.
Кнопка «Убрать всё» очищает документ после подтверждения. Файлы изображений
сохраняются.

Mustek Studio проверяет обновления при запуске. Запустить проверку вручную
можно в настройках кнопкой «Проверить обновления». После подтверждения
обновление установится и приложение снова откроется.

В приложении доступны предпросмотр, выбор DPI, PNG, многостраничный PDF,
импорт изображений, поворот страниц, русский и английский языки, две темы.
Установщик работает без интернета. На компьютере используется встроенный
.NET Framework Windows 10; WinUSB устанавливается отдельным подтверждением.
